# 제출 항목과 심사 배점 정책

- 제출 받을 항목 설정은 선택이다. 항목이 없어도 프로그램을 개설하고 기본 지원자·팀 정보로 지원할 수 있다.
- 추가한 개별 항목의 필수 여부는 별도로 적용한다. 필수 입력, 체크박스, 파일 검증과 기존 답변이 있는 항목의 삭제 방지는 유지한다.
- 기능이 연결되지 않았던 양식 다운로드 버튼은 제거한다.
- 심사 항목 생성·수정 API의 `maxScore`가 항목 배점이다. 필수이며 0보다 크고 999999.99 이하, 소수 둘째 자리까지 허용한다.
- 심사 점수는 0 이상 해당 항목 배점 이하, 소수 둘째 자리까지 허용한다. 최종 제출은 모든 항목 점수가 필요하다.
- 총 배점은 항목 배점의 합이며 100점으로 고정하지 않는다. 심사위원 총점은 입력 점수 합계이며 최종 점수는 제출한 심사위원 총점의 평균에 가산점을 더한다.
- 첫 임시저장 또는 제출 이후 배점·항목 추가·삭제·순서 변경을 차단한다(409). 항목 이름과 설명 수정은 허용한다. 심사 저장과 동일한 프로그램 행 잠금으로 동시 변경을 직렬화한다.
- V21은 기존 항목의 10점 배점, 저장 점수, 총점, 기존 weight 값을 보존한다. weight는 새 입력·합산에 사용하지 않으며 자동 변환하지 않는다.

검증: `CriterionMaxScoreIntegrationTests`, `CriterionMaxScoreMigrationTests`, `RequiredCheckboxIntegrationTests`, `EvaluationScoreReplacementIntegrationTests`, 프론트 `criteria.test.mjs` 및 기존 내보내기·기간 테스트.
