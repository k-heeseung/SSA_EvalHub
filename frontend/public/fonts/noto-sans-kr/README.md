# Noto Sans KR

Official variable font from google/fonts, ofl/notosanskr.

- Pinned commit: b38c5c93af322c45f633e17ac440ec1e6c94d489
- Source: https://github.com/google/fonts/tree/b38c5c93af322c45f633e17ac440ec1e6c94d489/ofl/notosanskr
- Original filename: NotoSansKR[wght].ttf
- Runtime filename: NotoSansKR-Variable.woff2
- Weight axis: 100–900
- Style: normal
- License: SIL Open Font License 1.1 (OFL.txt)

Approved as the shared application font after the manager-screen comparison.
The official TTF was losslessly converted to WOFF2 with FontTools/Brotli without
subsetting glyphs or weights (10,414,588 → 3,908,244 bytes). The original TTF and
unused comparison fonts are preserved under .impeccable/font-candidates/source-assets
at the repository root, outside production public assets. No external runtime
font request is required. The OFL license is retained alongside the runtime font.
